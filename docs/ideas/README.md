# Ideas

Sibling apps sketched on 2026-09-20, each a spec in DESIGN.md's shape plus the self-contained
HTML sketch its numbers come from, the way `prototypes/` holds the derby's pages. None is built.
The brainstorm boards they came from are private artifacts linked from each spec.

| Idea | Spec | Sketch | One line |
|---|---|---|---|
| Darkroom | [`darkroom.md`](darkroom.md) | [`darkroom-sketch.html`](darkroom-sketch.html) | rock the phone to develop your own photo under a safelight, then a hard cut to a warm-tone print |
| Formicarium | [`formicarium.md`](formicarium.md) | [`formicarium-sketch.html`](formicarium-sketch.html) | a pixel ant farm on the real clock, with sand physics that follows the phone's gravity |
| Home, 16-bit | [`home-16-bit.md`](home-16-bit.md) | [`home-16-bit-sketch.html`](home-16-bit-sketch.html) | scan your flat with RoomPlan and get it back as a top-down pixel map |

The sketches use the derby's sixteen colours at 320×224, whole pixels, and are reference code for
a future core package, function for function. Fonts come from Google Fonts; everything else is
inline.
